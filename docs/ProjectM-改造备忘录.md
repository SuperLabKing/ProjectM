# ProjectM 改造备忘录

## 2026-11-12 · dotpm 功能取舍

### 项目总仪表盘

- 保留左侧边栏按钮打开的「项目」总仪表盘。列表只展示顶层项目，子项目和任务留在各自的项目页面。
- 保留现有的进度、任务数、成员和截止日期。新增「开始时间」和「实际完成时间」两列。
- 待讨论日期的来源与写入时机，包括开始时间是计划值还是实际值，以及项目重新打开后如何处理实际完成时间。

### 项目导航

- 提供两种打开方式供选择。沿用现有的「在新标签页打开」，同时支持「在当前标签页打开」。
- 在当前标签页打开项目时，提供清晰的返回按钮，可以从项目页回到项目总仪表盘。
- 待讨论默认打开方式，以及返回后是否恢复筛选、排序和滚动位置。

### 单个项目的仪表盘

- 保留进入具体项目后看到的项目详情仪表盘及其现有操作。

### 任务面板

- 留待单独讨论。这部分预计改动较多，后续再确定要保留的视图和交互。
- 已有讨论项包括关联笔记在表格中的呈现、父任务状态与进度联动，以及项目和任务的手动排序。

### 数据结构与笔记属性

- 以 dotpm 现有的 Markdown 文件与 YAML 属性作为兼容基础，梳理哪些字段继续沿用、哪些需要新增或调整。
- 关联笔记直接指向原文件，关联关系和项目内状态由项目记录保存。
- 待讨论项目日期的字段名、数据类型及写入规则，以及已有项目和任务的兼容方式。
